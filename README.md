# LMS Android

Android-клиент для роутера LMS ([lms-client](https://github.com/x-happy-x/lms-client)):
работает с тем же API `/api/ui/*`, что и веб-интерфейс роутера.

## Возможности

- Список загрузок с прогрессом, скоростью и ETA; фильтр «Все / Активные»,
  обновление каждые 3 с, пока экран открыт, и свайпом вниз.
- Пауза, продолжение, повтор и отмена.
- Добавление загрузки: проверка ссылки на роутере (preflight), выбор ноды,
  способа загрузки (HTTP, yt-dlp, aria2c, торрент) и папки со свободным местом.
- «Поделиться» → «Скачать через LMS» из браузера, YouTube, мессенджеров;
  открытие `magnet:`-ссылок и http(s)-ссылок на `.torrent`.
- Уведомления о завершении и ошибках: сразу, пока приложение открыто, и
  в фоне через WorkManager (15 мин – 3 ч).

## Установка

Последняя версия: <https://github.com/x-happy-x/lms-android/releases/latest/download/lms-android.apk>

Откройте ссылку на телефоне, разрешите установку из браузера и установите APK.
Каждый пуш в `main` публикует новый релиз (версия `0.1.<номер сборки>`), обновление
ставится поверх предыдущего.

## Настройка

В настройках укажите адрес веб-интерфейса LMS на роутере, например
`192.168.1.1:8082` (схема по умолчанию `http://`). У `/api/ui` нет авторизации,
поэтому вне дома используйте VPN или прокси с паролем — для него есть поля
логина и пароля (HTTP Basic).

Торренты (`TORRENT`, magnet) требуют поддержки на роутере: сейчас lms-client
принимает только `http(s)`-ссылки и типы `DIRECT`/`YTDLP`/`ARIA2C`, magnet вернёт
ошибку роутера. Нода (lms-node) торренты уже умеет.

## Сборка

Требуется JDK 17+ и Android SDK (compileSdk 35).

```bash
./gradlew :core:test            # тесты API-клиента и логики
./gradlew :app:assembleDebug    # app/build/outputs/apk/debug/app-debug.apk
```

`./gradlew -PcoreOnly :core:test` собирает только модуль `core` (чистый Kotlin)
без Android SDK и Google Maven.

CI (GitHub Actions) запускает тесты, собирает debug/release APK (артефакты
запуска) и для `main` публикует релиз.

Release подписывается ключом из секретов репозитория (Settings → Secrets and
variables → Actions):

| Секрет | Значение |
| --- | --- |
| `LMS_KEYSTORE_BASE64` | keystore (`.jks`) в base64 |
| `LMS_KEYSTORE_PASSWORD` | пароль keystore |
| `LMS_KEY_ALIAS` | алиас ключа |
| `LMS_KEY_PASSWORD` | пароль ключа |

Без них release подписывается временным debug-ключом сборочной машины и не
публикуется: такое обновление не встало бы поверх установленной версии. Ключ нельзя терять: APK,
подписанный другим ключом, не обновит уже установленное приложение.

## Структура

- `core/` — модели, клиент API роутера (OkHttp + kotlinx.serialization),
  разбор ссылок, определение событий для уведомлений, форматирование.
- `app/` — Jetpack Compose UI (Material 3), DataStore для настроек,
  WorkManager для фоновой проверки.
