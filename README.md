# LMS Android

Android-клиент для роутера LMS ([lms-client](https://github.com/x-happy-x/lms-client)):
работает с тем же API `/api/ui/*`, что и веб-интерфейс роутера.

## Возможности

То же, что в веб-интерфейсе роутера:

- **Загрузки:** прогресс, скорость, ETA; иконки и цвета по типу файла, превью фото и
  видео; вкладки по статусу, фильтр по типу файла и ноде, поиск, сортировка и
  группировка (статус, тип, нода, дата), список или плитка. Пауза, продолжение,
  повтор, отмена, смена ссылки, перемещение на другую ноду или в другую папку.
- **Скачать на телефон:** готовый файл идёт с ноды через роутер в «Загрузки/LMS»
  (системный DownloadManager: прогресс, докачка, уведомление). Папки торрентов — ZIP.
- **Медиа:** галерея готовых фото и видео; просмотр на весь экран без скачивания —
  фото с зумом, видео с перемоткой (стриминг через роутер).
- **Добавление:** проверка ссылки на роутере, выбор ноды, способа загрузки (HTTP,
  yt-dlp, aria2c, торрент), профиля и папки со свободным местом; magnet-ссылки.
- **Ссылки из других приложений:** «Поделиться» → «Скачать через LMS», «Открыть с
  помощью» для любых http(s)-ссылок, видео/аудио и `.torrent`, `magnet:`, пункт
  «Скачать через LMS» в меню выделенного текста. По умолчанию открывается экран
  добавления. С настройкой «Добавлять без подтверждения» ссылка сразу уходит на лучшую
  ноду, а о результате сообщает всплывающее уведомление.
  Android 12+ открывает обычные ссылки в браузере по умолчанию. Если браузер
  по умолчанию выбран, пользуйтесь «Поделиться»: «Открыть с помощью» появляется
  в приложениях, которые показывают выбор программы.
- **Ограничение скорости:** при добавлении (по умолчанию — из настроек) и для уже идущей
  загрузки (меню → «Ограничить скорость»). HTTP-загрузки меняют скорость сразу,
  остальные перезапускаются с того же места.
- **Ноды:** статус, пинг, типы загрузок, диски; добавление и редактирование.
- **Профили:** список и создание.
- **Уведомления** о завершении и ошибках: сразу, пока приложение открыто, и в фоне
  через WorkManager (15 мин – 3 ч).

## Установка

Последняя версия: <https://github.com/x-happy-x/lms-android/releases/latest/download/lms-android.apk>

Откройте ссылку на телефоне, разрешите установку из браузера и установите APK.
Каждый пуш в `main` публикует новый релиз (версия `0.1.<номер сборки>`), обновление
ставится поверх предыдущего.

## Настройка

В настройках укажите адрес веб-интерфейса LMS на роутере, например
`192.168.1.1:8082` (схема по умолчанию `http://`). У `/api/ui` нет авторизации,
поэтому вне дома используйте VPN или прокси с паролем — для него есть поля
логина и пароля (HTTP Basic).

Торренты, скачивание на телефон, превью, просмотр медиа и ограничение скорости требуют
свежих lms-client (торренты, `/api/ui/jobs/{id}/file`, `/preview`, `/speed`) и lms-node
(Range, ZIP, ffmpeg, `/api/jobs/{id}/speed`).

## Сборка

Требуется JDK 17+ и Android SDK (compileSdk 35).

```bash
./gradlew :core:test            # тесты API-клиента и логики
./gradlew :app:assembleDebug    # app/build/outputs/apk/debug/app-debug.apk
```

`./gradlew -PcoreOnly :core:test` собирает только модуль `core` (чистый Kotlin)
без Android SDK и Google Maven.

CI (GitHub Actions) запускает тесты, собирает debug/release APK (артефакты
запуска) и для `main` публикует релиз.

Release подписывается ключом из секретов репозитория (Settings → Secrets and
variables → Actions):

| Секрет | Значение |
| --- | --- |
| `LMS_KEYSTORE_BASE64` | keystore (`.jks`) в base64 |
| `LMS_KEYSTORE_PASSWORD` | пароль keystore |
| `LMS_KEY_ALIAS` | алиас ключа |
| `LMS_KEY_PASSWORD` | пароль ключа |

Без них release подписывается временным debug-ключом сборочной машины и не
публикуется: такое обновление не встало бы поверх установленной версии. Ключ нельзя терять: APK,
подписанный другим ключом, не обновит уже установленное приложение.

## Структура

- `core/` — модели, клиент API роутера (OkHttp + kotlinx.serialization),
  разбор ссылок, определение событий для уведомлений, форматирование.
- `app/` — Jetpack Compose UI (Material 3), DataStore для настроек,
  WorkManager для фоновой проверки.
